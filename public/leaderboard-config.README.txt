SHARED LEADERBOARD — RUNTIME CONFIG
===================================

This file is read by the game WHILE IT RUNS. You do not need to rebuild the
app or change any code to connect a database.

Fill in your two Supabase values:

{
  "url": "https://YOUR-PROJECT.supabase.co",
  "key": "sb_publishable_xxxxxxxxxxxxxxxxxxxx"
}

Where to find them
------------------
Supabase dashboard -> your project -> Connect
  * Project URL      -> "url"
  * Publishable key  -> "key"   (starts with sb_publishable_)

NEVER put a secret key, service-role key, or database password here.
This file is downloaded by every player's browser and is fully public.
The database's own permissions are what protect the scores.

Before it will accept scores
----------------------------
1. Run ALL THREE migrations, in this order, in Supabase -> SQL Editor -> New query:
     supabase/migrations/202611070001_carecall_leaderboard.sql
     supabase/migrations/202611080001_carecall_top20_seed.sql
     supabase/migrations/202611090001_carecall_any_start.sql
   The second sets the board to 20 places and seeds the opening scores.
   The third lets every run compete wherever it started.
   (Already ran the first two? Running just the third is enough.)
2. Enable Authentication -> Providers -> Anonymous Sign-Ins.

How the board works
-------------------
One leaderboard: the top 20 of all players. There is no device/global switch.
A run that beats the 20th place is stored automatically once the player types a
name. New places push everyone below down one and the 20th falls off.

Until this file is filled in, the game shows the same twenty opening scores
locally, so a first deployment is never empty.

Fastest way to test
-------------------
In the game, open the score table and press SETUP. Paste the same two
values and press CONNECT & TEST. It checks the database immediately and
tells you exactly what is wrong if something is missing.

That SETUP button stores the values in YOUR browser only, which is ideal
for testing. This file is what switches the leaderboard on for EVERYONE.

After editing this file
-----------------------
Re-upload it next to index.html and hard-refresh the page. Because it is
fetched with cache disabled, no rebuild or redeploy of the app is needed.

Leave both values empty ("") to keep the game device-only.
