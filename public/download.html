Inside the package

Complete source — no build output, no dependencies, no secrets.

Upload to GitHub

About two minutes.

CREATE THE REPO

On GitHub choose New repository. Name it carecall-ward-rush and make it public.

UNZIP & SHOW HIDDEN

Reveal dotfiles so .github, .gitignore and .nvmrc are included.

UPLOAD CONTENTS

Drag everything inside the unzipped folder to the repo root — not the folder itself.

ENABLE PAGES

Settings → Pages → Source → GitHub Actions. The workflow is already in the package.

PLAY

Watch Actions finish, then open username.github.io/repo/.
