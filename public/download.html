Upload to GitHub

  1. Create a new GitHub repository.
  2. Unzip the package and show hidden files so .github, .gitignore, and .nvmrc are visible.
  3. Upload all files and folders inside the unzipped folder to the repository root.
  4. Open Settings → Pages and set Source to GitHub Actions.
  5. Wait for the Deploy to GitHub Pages workflow to finish.
Local scores included The game saves each player’s top scores on their device without any extra setup.
Shared scores optional To enable a leaderboard for everyone, follow docs/HIGH_SCORES.md after uploading.
Logo optional Add public/brand/logo.svg or public/brand/logo.png before deploying.
